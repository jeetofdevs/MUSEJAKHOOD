# musejak ($MUSEJAK)

Landing page for $MUSEJAK, a memecoin on Solana launched on pump.fun and paired with SOL.

It's a static site with no build step: open `index.html` or host the folder on Vercel, Netlify or GitHub Pages.

## Launch checklist
- `script.js`: set `CONTRACT_ADDRESS`, and change `ALLOCATIONS` if the tokenomics change
- `index.html`: replace the chart link, and the pump.fun links, with the real token URLs
- `assets/sol.png`: the SOL pair logo
